## Pacing and resilience

Scroll smoothing uses approximately 0.65–0.8-second scrub, controlled seek uses 1.15–1.2 seconds, request playback is 3.3 seconds. No idle animation loop is added to the 3D exhibits; the shared canvas renders only while visible and moving. Pixel ratio is capped at 1.5. Reduced motion removes the pinned opening/gallery/Journey, leaves content readable and keeps direct controls. `graphics=off` retains SVG fallback diagrams. ## Reference principles studied

- [Dennis Snellenberg](https://dennissnellenberg.com/): artifact scale, restrained navigation and direct interaction.
- [Awwwards scroll-portfolio reference](https://www.awwwards.com/inspiration/scroll-portfolio): directional changes and editorial scene progression.
- [GSAP ScrollTrigger](https://gsap.com/docs/v3/Plugins/ScrollTrigger/): reversible scroll timelines and horizontal container animation.
- [GSAP refresh ordering](https://gsap.com/docs/v3/Plugins/ScrollTrigger/static.sort()/): upstream pin distances must precede dependent scenes.
- [GSAP MorphSVGPlugin](https://gsap.com/docs/v3/Plugins/MorphSVGPlugin/): actual path interpolation, rather than scaling one unchanged symbol.
